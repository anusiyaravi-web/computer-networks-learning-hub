# Computer Networks Learning Hub 🌐

## About the Project
Computer Networks Learning Hub is a responsive educational website designed to help students learn basic computer networking concepts in an easy and interactive way.

## Features
- **Networking Fundamentals:** Learn about LAN, MAN, WAN, TCP/IP, DNS, and the OSI Model.
- **Network Topology Explorer:** Explore Star, Bus, Ring, and Mesh topologies.
- **Interactive Quiz:** Answer multiple-choice questions and check your score.
- **Responsive Design:** Access the website on desktop and mobile devices.
- **User-Friendly Interface:** Simple navigation and an attractive design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the networking topics, topology explorer, and quiz.

## Project Objective
The main objective of this project is to provide students with an interactive platform to understand computer networking fundamentals and improve their knowledge through quizzes.
